🧾 Script Name:
HPIA Download + Install + Run (Fallback Method)

📄 Description:
Uses .NET WebClient (more reliable in restricted environments) to download and install HPIA, then runs analysis + install silently.

⚠️ Safety Notes:

Non-destructive
Requires internet access
May need admin rights for installs/driver updates

💻 PowerShell Script:

# Download, install, and run HPIA in one go
$u="https://ftp.hp.com/pub/caps-softpaq/cmit/HPIA.exe";$f="$env:TEMP\HPIA.exe";(New-Object Net.WebClient).DownloadFile($u,$f);Start-Process $f -ArgumentList "/s" -Wait;Start-Process "C:\Program Files\HP\HPIA\HPIA.exe" -ArgumentList "/Operation:Analyze /Action:Install /Silent /ReportFolder:C:\Temp\HPIA" -Wait
